# Software Engineering Lab Experiments

## Overview
This repository contains the Software Engineering laboratory experiments completed as part of the B.Tech Artificial Intelligence and Data Science curriculum. The experiments focus on applying software engineering principles, project management techniques, UML modeling, version control, collaboration, documentation, and software development tools.

## Objectives
- Understand Software Development Life Cycle (SDLC).
- Learn software project planning and management.
- Practice UML modeling and software design.
- Gain experience with Git and GitHub version control.
- Use industry-standard software engineering tools.
- Apply Agile development methodologies.
- Document software development activities.
